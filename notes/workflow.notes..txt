# workflow
1. webclaw --urls-file <issuer>.urls.txt --output-dir output\<dt> --only-main-content
- output\<dt> contains files as <isin>.md
2. format2 --config <issuer>.rx.txt --input-dir output\<dt> --output-format [json|sql|csv] --output-dir <path>
- <path> contains 1 file with entries as defined in <issuer>.rx.txt, eg. <isin>,<dt>,<ask>,<bid>,...
3. bash script to store the output file (json or sql or csv) to Firebase
4. REST service that expose /certificates /quotes /... by reading Firebase
